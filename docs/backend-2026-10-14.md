# Backend work — 14 October 2026

Branch `backend-api-2026-10-14` (from `overhaul-2026-10-06`). Frontend untouched.

## What was added

**A REST API** (`backend/stocksense/api`, FastAPI). Until now the website could only
read raw Supabase tables, so most panels used sample data. The API serves everything
those panels need from real data. Run it with `python -m stocksense api` and open
http://localhost:8000/docs.

| Area | Endpoints | Source |
|---|---|---|
| Market | `/market/indices`, `/market/overview`, `/sectors` | Supabase |
| Stocks | `/stocks` (screener), `/stocks/search`, `/stocks/{symbol}`, `/stocks/{symbol}/history` | Supabase + Yahoo charts |
| Geopolitics | `/news`, `/geopolitics` | Live RSS: Economic Times, Livemint, Business Standard, Google News |
| IPOs | `/ipos`, `/ipos/listings` | NSE |
| Prospectus | `/prospectus/rules`, `/prospectus/scan` | Uploaded PDF |

Highlights:

- **Score breakdown.** `/stocks/{symbol}` explains a score metric by metric
  (P/E earned 16.2 of 20 points, …), plus the largest sector peers.
- **Real geopolitics.** Headlines are tagged with topics (conflict, oil, trade, interest
  rates, currency, commodities, defence, China, monsoon) and mapped to the Indian
  sectors they move. Sector exposure is the recency-weighted share of recent news about
  each sector. This replaces the hand-written list in the frontend's `lib/constants.ts`.
- **Live IPOs.** Open and upcoming NSE issues with category-wise subscription (QIB /
  HNI / retail) and a plain reading of demand so far, plus how recent listings have done
  against their issue price.
- **Prospectus scanner in Python.** Same 12 rules as the earlier web version, now a
  backend service any client can call.
- **Resilience.** Supabase down → serves the bundled snapshot. NSE down → `/ipos`
  returns 503 with a readable message. At most two prospectus scans run at once.

**Data quality.** 41 stocks had stopped updating because they left NSE's list (e.g.
GUJGASLTD and GSPL merged, TATAMOTORS demerged, ZOMATO renamed ETERNAL). Their last
readings kept showing up as big movers. The API now treats data more than 7 days older
than the latest run as stale and leaves it out of rankings. `python -m stocksense cleanup`
lists those stocks; `--apply` deletes them.

**Data refresh.** All prices, fundamentals and ownership data were refreshed on
14 Oct (2,608 prices, 2,605 stocks; 2,397 scored).

**Tests.** 57 tests, all offline (fixtures for Supabase, NSE, news and charts), in
under a second: `cd backend && pytest`.
